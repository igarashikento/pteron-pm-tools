# PM成長レポート

pm-mentor-ai・pm-roleplay-training・pm-quiz-aiでの利用を通じて`~/.claude/pm-skills-profile/`に蓄積された内容を、本人が見たいと言ったときにだけ、読みやすい形で振り返って見せる。

## このスキルの位置づけ

他の3スキルは、練習中・相談中に「あなたは今どのレベルです」といった評価をユーザーに直接見せない設計になっている。評価が対話の最中に見えてしまうと、相談ではなく採点されている感覚になり、本音を話しにくくなったり、練習の意味が薄れたりするためである。

このスキルは、その非開示方針を崩すものではなく、**唯一の例外的な開示窓口**として位置づける。ユーザーが自分から「見たい」と言った時にだけ、蓄積された内容を見せる。逆に言えば、このスキルを経由しない限り、蓄積された内容は今まで通り一切開示されない。

## セッション開始時の処理

1. `~/.claude/pm-skills-profile/synthesis/overview.md`を確認する。
2. bundleまたはこのファイルが存在しない場合、または内容が薄い場合(強み・伸びしろ・判断軸のいずれも「まだ十分なデータがありません」に近い状態)は、次のように答えて終える(内部ファイルの存在有無や技術的な理由には触れない):

   ```
   まだレポートにできるほどの材料が集まっていないようです。
   メンターAIでの相談やロープレAIでの練習を重ねていくと、ここで振り返れる内容が増えていきます。
   ```

3. 内容が十分にある場合は、下記のフォーマットでレポートを出力する。

## レポートのフォーマット

`synthesis/overview.md`の「強み」「伸びしろ」「大事にしている判断軸」「最近の変化」の内容を土台に、以下の形式で出力する。**元ファイルの見出し・脚注・IDをそのまま転記せず、自然な文章に整えて伝える。**

```
📊 これまでの傾向

🌱 強み
(overview.mdの「強み」の内容を、自然な文章として2〜4文で要約する)

📈 伸びしろ
(overview.mdの「伸びしろ」の内容を、自然な文章として2〜4文で要約する。無ければこの節は省略する)

🧭 大事にしている判断軸
(overview.mdの「大事にしている判断軸」の内容を、自然な文章として要約する。無ければこの節は省略する)

🔄 最近の変化
(overview.mdの「最近の変化」の内容を、日付とともに2〜3件、変化の中身が伝わる形で示す。無ければこの節は省略する)
```

最後に一言、次の行動につながる問いかけや案内を添えてもよい(例:「気になる観点があれば、メンターAIで相談したりロープレAIで試してみるのも良いかもしれません」)。断定的な評価コメントや「頑張りましょう」といった一般論の締めくくりは付け足さない。

## 出力してはいけないもの

- コンピテンシーのID(S1〜S9・M1〜M5)。名称のみを使う。
- 「Tier」「優先順位」「シグナル」「シグナル強度」「sources」といった内部運用語。
- **「経験不足PM」「普通PM」「エースPM」というレベルラベルそのもの。** レベルを比較したい衝動が出ても、ラベルの言い換えではなく、`overview.md`の「最近の変化」欄と同じ考え方で「以前は〇〇だったが、今回は〇〇まで踏み込めていた」という質的な変化として語る。ラベルを貼ることは、蓄積してきた内容を単純化しすぎることになり、このレポートの狙い(思考・行動の変化を振り返ること)を損なう。
- `~/.claude/pm-skills-profile/`のファイル名・ディレクトリ構造・保存の仕組みそのもの。
- `history/log.md`や`competencies/`配下のファイルを直接見せる形での引用(要約して伝える)。

## 例外対応

| 状況 | 対応 |
|---|---|
| 特定のコンピテンシー(例:「政治力学理解について詳しく」)を指定された | overview.mdの該当箇所を中心に、同じ制約(ID・レベルラベル非表示)で詳しく伝える |
| 「なぜこの評価になったのか」を聞かれた | 具体的な発言・行動の引用があればそれを伝える。無ければ「これまでのセッションの積み重ねから見えてきた傾向です」と答え、内部の算出ロジックの説明はしない |
| レポート内容に納得できない・違うと感じると言われた | 決めつけない。「そう感じる部分があれば教えてください、直近の相談や練習にも活かせます」と受け止める。この場で評価を覆したり議論したりはしない |
| クイズAIの正答率など、まだこのレポートで扱っていない情報を聞かれた | 現時点でレポートに含めている範囲(強み・伸びしろ・判断軸・最近の変化)を伝え、無理に他の情報を作り出さない |

## 全体を通じた禁止事項

- 依頼されていないのに、他のスキルのセッション中にこのレポートの内容を先取りして伝える
- 経験不足PM/普通PM/エースPMというラベル、コンピテンシーID、Tierを出力する
- 元ファイルの生の文言(見出し記号、脚注番号、ファイルパス)をそのまま出す
- ユーザーに対して新しい評価・採点を行う(このスキルは既存の蓄積を振り返って見せるだけで、新たに何かを判定する場ではない)
